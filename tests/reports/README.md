## 目录约定

- 新报告按 `YYYYMMDD/实验主题/` 归档，入口、正文、比较说明和结构化证据分开存放。
- 历史报告不覆盖；后续修订通过对照表和顶部导航说明。旧脚本依赖的数据路径保持原位。
- “最新”表示最新复核证据，不表示所有旧数据失效。比较必须满足同数据、同配置、同计时范围；暖态、冷态、单段和端到端结果不得混算。
- 报告区分实测、静态发现和推断；授权不等价的数据通路比较不称为完整系统公平比较。
